📡 Live Data Sources

Data is pulled directly from each vendor's public Atlassian Statuspage JSON API. No proxy or server required — your browser calls the endpoints directly. Incident history is accumulated in your browser's local storage.

⚠️ Vendors Without Public Feeds

Epic, Oracle Health/Cerner, and ModMed do not publish public status APIs. Their cards show "No Public Feed" with a link to check manually. Consider a third-party uptime monitor (UptimeRobot) for these.

💡 Sales Prospecting Tip

Red cards = live outage, warm-call right now. Amber cards = outage in last 3 days, pain is still fresh. Yellow badge = incident in last 7 days, still a valid opener. Click "Copy opener" for ready-to-send outreach text.
